Shepu\'s Snake — Android Release Package
==========================================

Folder structure:
  main.py              App entry point
  engine.py            Game engine
  controls.py          Touch controls (swipe/joystick)
  entities.py          Snake, food, boss
  config.py            Settings
  utils.py             Save/load + Android helpers
  assets_manager.py    Images & sounds
  ui.py                UI components
  animation.py         Splash animation
  buildozer.spec       APK build config
  requirements.txt     Python dependencies
  game_data.txt        Player save data
  snake.png            App icon
  assets/              Game media files
  colab/               Google Colab build scripts
  docs/                Bengali APK build guide
